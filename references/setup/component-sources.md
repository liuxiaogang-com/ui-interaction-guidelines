# 组件来源与选型

## 选择顺序
以国际主流方案为准。项目已经在使用的组件库，无论来自哪里，都照常优先使用。

1. **项目已引入的组件库或组件**。先查 `package.json` 和项目的组件目录。
2. **已有组件实现不了时，引入一个单独的轻量组件**，只解决这一个问题。引入前征得需求方同意。禁止为一个组件引入整套 UI 库。
3. **浏览器原生能力**：只用于组件文件中写明可以用原生实现的组件（目前只有 `modal.md` 和 `drawer.md`），并满足其中的条件。其他组件禁止用原生实现代替。

无论哪种来源，复杂组件（弹窗、抽屉、下拉、日期选择、Tooltip）的滚动锁定、焦点管理和浮层定位，都禁止自己编写代码实现。组件库内部的实现不受限制。

## 引入新组件前的检查
- 近 12 个月内有发版，代码仓库没有归档。
- 知名度高：下载量大，或被主流组件库采用。
- 官方声明的浏览器支持范围覆盖项目的 Browserslist。
- 不带样式，或样式可以完全覆盖，不影响项目自定的视觉风格。
- 体积小，只安装需要的那个包。
- 和项目使用的框架匹配。

## 默认候选
以下是 2026 年 11 月整理时成熟、常用的选择。引入前按上面的检查项核对当前状态。

| 需求 | React | Vue | 原生 JS 或其他 |
|---|---|---|---|
| 弹窗、抽屉 | `@radix-ui/react-dialog` 或 Headless UI | Reka UI（原 Radix Vue） | `focus-trap` 加切换滚动锁定的类 |
| 下拉、Tooltip、气泡等浮层定位 | `@floating-ui/react` | `@floating-ui/vue` | `@floating-ui/dom` |
| 只缺焦点锁定 | `focus-trap`（各框架都有封装） | 同左 | 同左 |

- Radix、Headless UI、Reka UI 已包含背景滚动锁定和 iOS 兼容处理。
- 原生 JS 项目没有成熟的无头弹窗方案时，用 `focus-trap` 管理焦点。打开时给 `html` 加一个 `overflow: hidden` 的类，关闭时移除。
- 这些库多为其他组件库的底层依赖，开发者直接接触得少，但下载量和维护状态都处于前列。

## 禁止新引入
- Popper.js：已由 Floating UI 取代。
- Tippy.js：2024 年已归档。
- body-scroll-lock：长期没有发版。
