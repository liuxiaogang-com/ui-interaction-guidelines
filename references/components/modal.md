# 模态弹窗 Modal

## 选择页面、抽屉还是弹窗
- **弹窗**：简短确认、6 个以内的字段、用户不需要参考背景内容。
- **抽屉**：查看详情、字段较多、需要对照页面内容。
- **独立页面**：内容复杂、步骤多、需要可分享的链接。

## 通用
- 提供明确的关闭方式：右上角关闭图标，以及「取消」按钮。
- 点击遮罩：纯展示类弹窗可以关闭。含表单的弹窗禁止点遮罩关闭，防止误触丢失内容。
- 打开后焦点移入弹窗。关闭后焦点回到触发按钮。
- 锁定背景滚动。关闭后恢复原来的滚动位置。
- 长内容固定头部和底部按钮，只滚动中间区域。整体高度限制在可视区域内。
- 切换内部 Tab 或步骤时，弹窗高度保持稳定。为内容区设定固定或最小高度。
- 底部按钮最多 3 个：一个主操作、一个取消，必要时加一个次要操作。
- 最多叠加两层：内容弹窗上再弹出确认框。

## 桌面
- 按 Esc 关闭。
- 宽度按内容分为小、中、大几档，避免全部撑满屏幕。

## 移动
- 改用底部面板。内容多时改用全屏页，顶部提供返回或关闭。
- 软键盘弹出后，输入框和底部按钮保持可见。
- 适配 iOS 底部安全区。
- 高度用动态视口单位计算，禁止写死超出视口的高度。

## 常见错误
- 弹窗高度超出屏幕，底部按钮看不到。
- 弹窗内滚动到底后，背景页面跟着滚动。
- 填了一半的表单，点遮罩后全部丢失。
