# 抽屉与底部面板 Drawer / Bottom Sheet

## 实现方式
- 带遮罩的抽屉和底部面板，实现方式、选择顺序和禁止的做法都同 `modal.md`。
- 不带遮罩的侧栏不锁定背景滚动和焦点。用户可以继续操作背景页面。

## 通用
- 用于查看详情、编辑较多字段、需要对照背景内容的任务。
- 头部固定标题和关闭按钮，底部固定操作按钮，中间区域滚动。
- 有未保存内容时，关闭前先确认。
- 在详情抽屉中点击编辑，在同一个抽屉内切换为编辑状态。
- 禁止抽屉里再打开抽屉。

## 桌面
- 从右侧滑出，宽度按内容取 400～800px。
- 按 Esc 关闭。

## 移动（底部面板）
- 从底部弹出，顶部有拖动条或关闭按钮。
- 高度随内容变化，最高约为屏幕的 90%，超出部分内部滚动。
- 支持下滑关闭。面板内有已输入内容时，下滑关闭前先确认。
- 适配 iOS 底部安全区。
- 系统返回键的处理同 `modal.md` 的「移动」。

## 常见错误
- 抽屉内容很长，底部按钮跟着滚出视野。
- 移动端照搬桌面的右侧抽屉，内容被挤成窄条。
