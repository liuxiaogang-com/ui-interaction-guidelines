# 表格 Table

## 通用
- 列顺序：标识列（名称、编号）在最前，操作列在最后。
- 文本左对齐。数字和金额右对齐，并使用等宽数字（`font-variant-numeric: tabular-nums`）。状态用标签展示。
- 长文本截断并显示省略号，悬停或点击查看全文。
- 空值统一显示为「-」。
- 列多时表头固定，首列和操作列固定，中间横向滚动。
- 操作列最多直接展示 2 个操作，其余放进「更多」。
- 排序和筛选状态在表头可见。
- 批量操作：勾选后在表格上方出现批量操作栏，显示已选数量。
- 行操作成功后只更新该行。分页、筛选、滚动位置保持不变。
- 加载、空、失败状态显示在表格区域内，保留表头。
- 列宽固定，不随数据变化跳动。

## 桌面
- 行悬停时高亮。
- 点击整行打开详情时，整行都可点击，并显示手型光标。

## 移动
- 改为卡片列表。每张卡片展示 3～5 个关键字段，点击进入详情。
- 数据对比是核心任务时，才使用横向滚动的表格。

## 常见错误
- 操作列并排六个按钮。
- 数字左对齐，难以比较大小。
- 删除一行后整个表格刷新并跳回第一页。
