# Toast、通知与提示条 Toast / Notification / Alert

## 通用
- Toast 用于操作结果的简短反馈，如「已保存」，约 3 秒后自动消失。
- 错误提示停留更久，或由用户手动关闭。内容写明原因。
- 同类提示合并显示，避免短时间内叠出一串。
- Toast 只做通知。需要用户决定的事，用确认框。
- 带「撤销」的提示至少停留 5 秒。点击撤销后，数据回到原来的位置，列表不重新加载。
- 表单字段的错误显示在字段旁边，禁止用 Toast 提示。
- 页面级的持续状态（如「账号将于 3 天后到期」）用页面顶部的提示条。

## 桌面
- 显示在顶部居中或右上角，位置全项目统一。页面有固定顶栏时，显示在顶栏下方。

## 移动
- 显示在顶部或屏幕中部，避开底部按钮和 TabBar。

## 常见错误
- 操作成功后弹出一个必须点「确定」的对话框。
- 错误只显示「操作失败」，没有原因。
