# 输入框 Input

## 通用
- 每个输入框都有可见的标签。占位文字只用来示范格式，不能代替标签。
- 聚焦、错误、禁用、只读四种状态明显不同。
- 按内容设置输入类型：手机号、数字、邮箱、密码、搜索。
- 有长度限制时显示字数统计。
- 可清空的输入框提供清除按钮。
- 密码框提供显示 / 隐藏切换。

## 桌面
- 在单行输入框中按回车，提交所在表单。
- 输入框宽度和内容长度匹配。手机号、验证码用短输入框，地址、备注用长输入框。

## 移动
- 聚焦时页面禁止放大。字号至少 16px，其余措施见 `references/setup/base-styles.md` 的「禁止页面缩放」。
- 设置 `inputmode`，调出对应键盘：数字、电话、邮箱。
- 软键盘弹出后，当前输入框和提交按钮保持可见。

## 常见错误
- 只有占位文字没有标签，输入后用户忘了这一栏填什么。
- 所有输入框都撑满整行。
