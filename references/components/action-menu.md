# 更多操作菜单与操作面板 Dropdown Menu / Action Sheet

## 通用
- 用于收纳次要操作。触发器用「更多」图标或文字。
- 菜单项用动词。危险操作放在最后，使用危险色，并用分隔线隔开。
- 不可用的菜单项置灰并说明原因，或直接隐藏。
- 菜单项最多 8 个。更多时分组。

## 桌面
- 点击打开。悬停打开只用于顶部导航菜单。
- 浮层规则同下拉选择：不被父容器裁切、点击外部关闭、按 Esc 关闭、支持键盘操作。

## 移动
- 用底部操作面板，底部带「取消」。
- 长按可以唤起菜单时，同时提供一个可见的入口。

## 常见错误
- 表格行内的菜单被表格的 `overflow` 裁掉。
- 危险操作和普通操作混排在一起。
