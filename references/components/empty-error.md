# 空状态与错误状态 Empty / Error

## 通用
- 区分三种空状态：首次使用还没有数据、筛选或搜索没有结果、没有权限。
- **首次使用**：说明这里会出现什么，并提供创建入口。
- **筛选无结果**：显示当前条件，提供「清除筛选」。
- **没有权限**：说明原因和申请方式。
- **加载失败**：说明原因并提供重试。局部失败只影响该区块。
- 404 和错误页提供返回首页或上一页的入口。
- 空状态插图保持简洁，和项目风格一致。禁止用 Emoji。

## 常见错误
- 空表格只显示表头，用户以为还在加载。
- 搜索无结果只显示「暂无数据」，用户无法判断是没有数据还是搜索出错。
