# 搜索与筛选栏 Search / Filter Bar

## 通用
- 常用的 2～4 个筛选条件直接展示，其余收进「更多筛选」。
- 搜索框的占位文字说明能搜什么，如「搜索订单号或手机号」。
- 搜索触发方式全项目统一一种：停止输入约 300ms 后自动搜索，或按回车搜索。
- 中文输入法拼写过程中不触发搜索。确认上屏后再按上一条的方式触发。
- 条件快速变化时，只显示最后一次请求的结果。较早发出的请求晚返回时，丢弃它的结果。
- 已生效的筛选条件可见，可以单独清除，并提供「重置」。
- 筛选条件写入 URL。
- 修改筛选或搜索后，保留其他条件，回到第一页。

## 桌面
- 筛选栏在列表上方横向排列，空间不够时换行。

## 移动
- 搜索框放在顶部。
- 筛选条件放进底部面板，点击「查看结果」后生效。
- 面板打开时，用当前生效的条件初始化一份草稿。在面板内的修改只改草稿，关闭面板时丢弃。
- 面板打开期间，列表加载或刷新不能覆盖用户在草稿中的选择。
- 面板底部提供「重置」，只清空草稿。
- 筛选按钮上显示已选条件的数量。

## 常见错误
- 十几个筛选字段全部平铺在页面顶部。
- 翻页后筛选条件丢失。
- 快速输入或切换条件后，列表最后显示的是较早一次请求的结果。
- 移动端筛选面板中刚选好的条件，被后台刷新的列表重置。
