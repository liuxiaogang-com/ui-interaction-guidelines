# 菜单与导航 Menu / Sidebar / TabBar / NavBar

## 桌面
- 侧栏菜单超出高度时独立滚动，所有菜单项都能访问。
- 高亮当前页面所在的菜单项，并展开它所在的分组。
- 菜单层级最多 3 层。
- 侧栏可以折叠为图标模式。折叠后悬停显示菜单名称。
- 顶部栏固定，不遮挡主内容。
- 二级及更深的页面显示面包屑。

## 移动
- 一级入口 2～5 个时用底部 TabBar：图标加文字，高亮当前项，适配底部安全区。
- 二级页面使用顶部导航栏，包含返回按钮和页面标题。
- 返回上一页时，恢复它的滚动位置和状态。
- 低频入口放进「我的」页面或抽屉菜单。

## 常见错误
- 侧栏菜单超出高度被直接裁掉。
- 移动端把桌面侧栏原样塞进页面。
