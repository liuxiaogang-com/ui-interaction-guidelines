# 交互状态与动效 Hover / Press / Focus / Motion

## 适用范围
所有能点击或触摸的元素：按钮、图标按钮、链接、Tab、分段控件、筛选标签、菜单项、导航项、列表项、可点击的卡片和表格行、下拉触发器、单选、多选、开关。

按钮的尺寸和六种状态细则见 `button.md`。

## 通用
- 每个可点击元素都定义悬停、按下、键盘焦点、禁用四种状态。选中类控件再定义选中状态。
- 按下反馈在手指或鼠标按下的瞬间出现，松开后恢复。禁止等到松开或请求返回后才有变化。
- 按下反馈从以下方式中选择，同类元素全项目保持一致：
  - 底色或文字颜色加深、变浅。
  - 轻微缩小：按钮约 0.97，卡片约 0.98。占满整行的列表项和表格行改用底色变化。
  - 透明度降低，适合纯图标和文字链接。
- 点击后立即跳转或打开弹层时，按下反馈照常出现。弹层用淡入或滑入动画出现，禁止瞬间出现。
- 跳转或打开需要等待数据时，在被点击的元素上或页面顶部显示加载，见 `loading.md`。禁止点击后界面静止不动地等待。
- 选中类控件切换时有过渡：开关滑块滑动，复选框打勾，Tab 指示条移到新位置。
- 反馈只表达状态。禁止为了播放动画而推迟跳转或请求。

## 动效
- 过渡时长：颜色和透明度约 100～150ms。弹层和面板出现约 150～250ms，退出比出现略快。
- 用 `ease-out` 类缓动。弹跳、回弹等夸张效果只在视觉方向明确需要时使用。
- 只对 `transform`、`opacity` 和颜色做过渡。禁止对宽高、边距、`top`、`left` 做过渡，它们会引起布局抖动和卡顿。
- 系统开启「减少动态效果」（`prefers-reduced-motion: reduce`）时，取消缩放、滑动和位移，保留颜色变化。

## 桌面
- 悬停时底色、文字颜色或边框颜色发生变化。
- 卡片、表格行、文字链接等非按钮元素可点击时，显示手型光标。
- 按下比悬停更明显。两者使用不同的样式。
- 禁用元素不显示悬停和按下效果。

## 移动
- 每次触摸都有按下反馈。iOS 上让 `:active` 生效的方法见 `references/setup/base-styles.md` 的「跨平台控件外观」。
- 悬停样式写在 `@media (hover: hover)` 里，避免点击后残留。
- 关闭系统默认的点击高亮后，必须提供自己的按下反馈。

## 常见错误
- 点击列表项或卡片后界面没有变化，过一会儿才跳转。用户以为没点上，又点了一次。
- 只有按钮有反馈，Tab、菜单项、卡片、导航项点了没有反应。
- 弹窗瞬间出现、瞬间消失，看不出是哪个操作打开的。
- 悬停和按下是同一个样式，按下时感觉不到点上了。
- 大卡片按下时缩放过大，显得整块在晃。
