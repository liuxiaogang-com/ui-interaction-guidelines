# 单选、多选、开关 Radio / Checkbox / Switch

## 通用
- Radio 用于互斥选项。有合理默认值时，默认选中最常用的一项。
- Checkbox 用于多选，以及「同意协议」这类单项确认。
- Switch 用于立即生效的开启 / 关闭。需要点「保存」才生效的表单里，改用 Checkbox。
- 二选一的两个选项各有名称时（如「按月 / 按年」），用 Radio。
- 开关旁写明它控制什么。开关本身表达当前状态。
- 点击文字标签也能切换。
- 选项多时分组排列。超过 5 个时改用下拉选择。
- Switch 切换后需要请求接口时，显示加载状态。失败时恢复原状态并提示。

## 桌面
- 横向排列的选项之间留足间距，避免误点。

## 移动
- 整行可点击，触控高度至少 44px。
- 选项纵向排列。

## 常见错误
- 二选一用下拉选择。
- 开关切换后请求失败，开关停在错误的状态。
