# 日期时间选择 DatePicker

## 通用
- 日期显示格式全项目统一，如 `2026-11-20`。
- 按业务提供快捷选项，如「今天」「最近 7 天」「本月」。
- 不可选的日期置灰，如早于今天的日期。
- 范围选择时，开始日期不能晚于结束日期。选完开始日期后自动切到结束日期。
- 支持清空。
- 前后端统一时区规则，避免日期差一天。

## 桌面
- 浮层规则同下拉选择：不被裁切、点击外部关闭、按 Esc 关闭。
- 支持手动输入日期，格式错误时提示。

## 移动
- 用底部面板加滚轮或日历选择。
- 避免在小屏上弹出小尺寸的浮层日历。

## 常见错误
- 直接用原生日期输入框，各浏览器外观和格式不一致。
- 范围选择允许结束日期早于开始日期。
