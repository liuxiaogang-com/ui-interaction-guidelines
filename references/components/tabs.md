# Tab、分段控件与分类筛选 Tabs / Segmented / Filter Chips

## 通用
- 用于同一层级内容之间的切换。
- 所有选项呈现为一组控件：统一排列、间距和点击区域，配合容器、底线或指示条表达分组。每项不必单独加描边或大底色。
- 选中项组合使用字重、颜色、底色或指示线来突出。
- 未选中项看起来可以点击。它和普通正文、禁用文字明显不同。
- 切换时内容区高度尽量稳定。各 Tab 的滚动位置和已填写内容保持不变。
- 页面级 Tab 的当前项写入 URL。
- 2～5 个选项用 Tab 或分段控件。更多时横向滚动，或改用下拉。

## 桌面
- 提供悬停和焦点反馈。
- 支持键盘左右切换。

## 移动
- 不靠悬停也能看出每一项都可点击。
- 选项超出宽度时横向滚动，露出半个选项，提示可以滑动。
- 当前项自动滚入可视区域。
- 页面级 Tab 滚动时吸顶。

## 常见错误
- 未选中项是灰色普通文字，看不出能点。
- 切换 Tab 时弹窗高度跳动。
