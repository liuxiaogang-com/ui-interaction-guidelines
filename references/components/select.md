# 下拉选择 Select

适用：从较多选项中选一个或多个值。选项 5 个以内时，改用 `choice.md` 中的单选或多选。

## 通用
- 触发器显示当前值。没有值时显示占位文字。
- 打开时高亮当前选中项，并滚动到它所在的位置。
- 选项超过 15 个时提供搜索。搜索无结果时显示空状态。
- 可清空的字段提供清除按钮。
- 多选时已选项以标签显示在触发器内。放不下时显示「+N」。
- 级联选择逐级展开，已选路径完整显示，如「广东 / 深圳 / 南山」。
- 远程加载选项时，浮层内显示加载状态。

## 桌面
- 浮层在触发器下方展开。靠近视口底部时向上展开。
- 浮层挂载到页面顶层，避免被父容器的 `overflow` 裁切。
- 浮层内选项超过 8 个时内部滚动。
- 点击外部或按 Esc 关闭。单选选中后自动关闭，多选保持打开。
- 支持键盘上下移动、回车选中。
- 触发器宽度固定，不随选中内容变化。

## 移动
- 改用底部弹出面板，选项高度至少 44px。
- 选项多时用滚轮选择器，或带搜索的全屏列表。
- 多选面板底部提供「确定」按钮。

## 常见错误
- 浮层在表格或弹窗内被裁掉一半。
- 二选一也用下拉。
- 打开后看不出当前选的是哪一项。
